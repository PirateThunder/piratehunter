# Демо-видео PirateHunter (ЛЦТ 2026, спец. трек ФСП)

`piratehunter-demo.mp4` — сквозной сценарий платформы (2:39, 1920×1080, H.264,
30 fps, без звука). Титры — DOM-плашки, вшитые на этапе записи (не отрываются
при пересъёмке, шрифт Inter/JetBrains Mono наследуется из страницы).

## Пересъёмка

```bash
# стенд должен быть поднят (docker compose up -d), фронт на :56151
../../scripts/seed.sh                       # эталонное состояние данных
cd src
bun install && bunx playwright install chromium   # один раз
node record.mjs                              # все сцены → ../scenes/*.webm
node record.mjs --only 04                    # одна сцена
node record.mjs --only 07 --prestage         # сцена 07 без 05: приглашение через API
bash assemble.sh                             # scenes/*.webm → ../piratehunter-demo.mp4
../../scripts/seed.sh                        # вернуть стенд в эталон
```

- `lib.mjs` — playwright-харнес (1920×1080, recordVideo webm), DOM-оверлеи
  (`chrome(page, caption, sub)`), хелперы кликов/ввода, evalPython для честных
  ответов mcq. Snap-изоляция: временные файлы chromium — только из $HOME.
- Сцены `s01-03.mjs`, `s04-05.mjs`, `s06-07.mjs`, `s08-10.mjs`; порядок и
  оркестрация — `record.mjs`. Непрерывность данных: приглашение сцены 05
  видно в инбоксе сцены 07 (один прогон = один датасет после seed.sh).
- `assemble.sh` — нормализация каждой сцены (h264/yuv420p/30fps/1920×1080) +
  concat demuxer. Промежутки — `build/norm/`.
