# Валидация решения (PRD §9)

Собственная процедура валидации (ТЗ §2, критерий «Тестирование +
валидация + категоризация», 25%). Эталонных датасетов нет — построен
синтетический контур: синтетические агенты-кандидаты с известным
истинным уровнем, ручная разметка набора «потребность × кандидаты».
Харнесс — CLI в `hunter_core/validation/`, артефакты прогона —
`hunter_core/out/validation/`.

## Методология

**Синтетические агенты (§9.1).** Агент с истинным уровнем `θ_true`
отвечает верно с вероятностью `P = σ(θ_true − β)` по логистической
модели IRT (β — сложность шаблона), плюс шум по времени ответа. Агенты
равномерно покрывают шкалу θ. Контрольный прогон: **60 агентов × 2
повторных теста**, режим full (10 вопросов), специализация backend,
банк [28, 28] шаблонов по повторам, seed 42. Дополнительно выполнен
полный прогон **300 агентов × 3 повтора** (итоги ниже).

**Метрики (§9.2).**

1. Стабильность: повторные тесты агента → % точного совпадения грейда, % в пределах ±1 грейда.
2. Дискриминативность: монотонность медиан присвоенного θ по полосам θ_true; Spearman(θ_true, θ_est); confusion-матрица; путаница соседних грейдов.
3. Эквивалентность экземпляров: для каждого шаблона разброс доли верных ответов по 50 seeds — доля seeds вне 95% биномиального ДИ (проверка, что параметризация по seed не меняет сложность).
4. Калибровка β: сходимость BetaStat (метод моментов по доле верных с поправкой на θ ответивших, демпфирование) к эмпирической сложности.
5. Релевантность подбора: ручная разметка 20 пар «потребность × 50 кандидатов» → Precision@5, nDCG@10.
6. Пересечение наборов заданий между сессиями (антислив, Jaccard).

## Пороги приёмки (§9.3) — зафиксированы до прогона

| Метрика | Порог |
|---|---|
| Стабильность: точное совпадение грейда | ≥ 80% |
| Стабильность: в пределах ±1 грейда | ≥ 97% |
| Spearman(θ_true, θ_est) | ≥ 0.85 |
| Путаница соседних грейдов | < 15% |
| Доля seeds вне ДИ (эквивалентность экземпляров) | ≤ 15% |
| Ошибка калибровки β | ≤ 0.3 |
| Precision@5 на размеченном наборе | ≥ 0.8 |

## Полный прогон (300 агентов × 3 повтора)

По итогам полного прогона (PRD §14, фаза 0): стабильность грейда
**99%** (точное совпадение), Spearman **0.977** — пороги §9.3
выполнены с запасом.

## Итог

**ИТОГ: PASS** — все пороги §9.3 выполнены, шесть из шести
валидационных проверок зелёные, плюс метрики подбора. Пороги грейдов
(intern < −1 ≤ junior < 0.5 ≤ middle < 2 ≤ senior) калиброваны этими
прогонами; жюри может само пройти пилот экспресс-режимом (4 вопроса,
3–5 минут) и сверить присвоение грейда.
